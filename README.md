## Sobre

Desenvolvo aplicações web desde 2018 e hoje atuo como **Full Stack Sênior na Vena**, no **App Financeiro para consultores**: análise de resultados, fluxo de caixa, capital de giro e projeções. Nesse produto, trabalho com React, TypeScript, C#/.NET, PostgreSQL e AWS.

Minha trajetória tem uma base forte em **Vue.js e TypeScript**, além de experiência com Node.js, PHP e Laravel. Gosto de transformar regras de negócio em interfaces claras, componentes reutilizáveis e serviços bem organizados.
